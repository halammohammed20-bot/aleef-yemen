# أليف - منصة الحيوانات الأليفة 🐾

منصة يمنية لتبني الحيوانات الأليفة، التزاوج، والإبلاغ عن الحيوانات المفقودة.
الآن الموقع **مربوط بقاعدة بيانات حقيقية (Supabase)** بدلاً من التخزين الوهمي في المتصفح، وجاهز للنشر المجاني على **Vercel**.

## ما الذي تغيّر؟

كان الموقع يخزّن كل شيء (الحيوانات، العيادات، المستخدمين، المفضلة) في `localStorage` بالمتصفح، أي أن البيانات:
- تختفي عند تغيير الجهاز أو مسح المتصفح.
- غير مشتركة بين الزوار؛ كل شخص يرى نسخته الخاصة فقط.

الآن تم ربط الموقع بـ **Supabase** (قاعدة بيانات Postgres + نظام تسجيل دخول حقيقي + تخزين، مجاناً)، فأصبحت البيانات:
- محفوظة فعلياً في قاعدة بيانات سحابية واحدة يشترك فيها كل الزوار.
- تسجيل الدخول حقيقي (بريد إلكتروني + كلمة مرور، مع تشفير وتأكيد بريد اختياري).
- قابلة للنسخ الاحتياطي والتوسّع لاحقاً.

## خطوات التشغيل (من الصفر حتى النشر)

### 1) إنشاء مشروع Supabase (مجاني)

1. اذهب إلى https://supabase.com وأنشئ حساباً مجانياً، ثم اضغط **New Project**.
2. اختر اسماً وكلمة مرور لقاعدة البيانات (احفظها في مكان آمن) والمنطقة الأقرب لك.
3. بعد إنشاء المشروع، اذهب إلى **SQL Editor** من القائمة الجانبية.
4. افتح ملف `supabase/schema.sql` من هذا المشروع، انسخ محتواه بالكامل، الصقه في محرر SQL بـ Supabase، واضغط **RUN**.
   - هذا ينشئ كل الجداول (`pets`, `clinics`, `clinic_comments`, `community_posts`, `favorites`, `profiles`) مع قواعد الحماية (RLS).
5. (اختياري لكن موصى به) افتح ملف `supabase/seed.sql`، انسخه، والصقه، واضغط **RUN** لإضافة عيادات ومنشورات مجتمع تجريبية حتى لا يبدو الموقع فارغاً عند أول زيارة.
6. اذهب إلى **Project Settings > API** وانسخ:
   - `Project URL` → هذه قيمة `VITE_SUPABASE_URL`
   - `anon public` key → هذه قيمة `VITE_SUPABASE_ANON_KEY`
7. لا حاجة لأي خطوة يدوية في Storage — ملف `schema.sql` ينشئ تلقائياً Bucket باسم `aleef-media` (عام/Public) مع كل صلاحيات الرفع والحماية اللازمة. كل صور الحيوانات، صور العيادات، والفيديوهات التي يرفعها المستخدمون تُخزَّن فيه مباشرة وتُحفظ روابطها العامة في قاعدة البيانات.
8. من **Authentication > Providers**، تأكد أن **Email** مفعّل. يمكنك أيضاً من **Authentication > Settings** إيقاف "Confirm email" إذا رغبت أن يدخل المستخدم مباشرة بعد التسجيل دون تأكيد بريد (مناسب للتجربة السريعة).

### 2) تشغيل الموقع محلياً

```bash
npm install
cp .env.example .env.local
```

عدّل `.env.local` وضع فيه القيم الحقيقية:

```
VITE_SUPABASE_URL="https://xxxxxxxx.supabase.co"
VITE_SUPABASE_ANON_KEY="..."
GEMINI_API_KEY="..."   # اختياري، لتفعيل مستشار أليف الذكي
```

ثم شغّل:

```bash
npm run dev
```

افتح `http://localhost:3000` وجرّب: تسجيل حساب، إضافة حيوان، تعليق على عيادة، إضافة للمفضلة.

### 3) رفع المشروع إلى GitHub

```bash
git init
git add .
git commit -m "Aleef platform with Supabase backend"
```

أنشئ مستودعاً جديداً على GitHub وادفع الكود إليه (`git remote add origin ...` ثم `git push`).

### 4) النشر المجاني على Vercel

1. اذهب إلى https://vercel.com وسجّل الدخول بحساب GitHub.
2. اضغط **Add New... > Project** واختر المستودع الذي رفعته.
3. Vercel سيكتشف تلقائياً أنه مشروع Vite (Build Command: `vite build`, Output: `dist`) — هذا معرّف مسبقاً في `vercel.json`.
4. قبل الضغط على Deploy، افتح قسم **Environment Variables** وأضف:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
   - `GEMINI_API_KEY` (اختياري)
5. اضغط **Deploy**. خلال دقيقة أو دقيقتين سيصبح موقعك منشوراً فعلياً على رابط مجاني مثل:
   `https://aleef-yourname.vercel.app`

كل زيارة جديدة للموقع الآن تتصل بنفس قاعدة بيانات Supabase — فأي شخص يضيف حيواناً سيظهر لجميع الزوار.

## لوحة تحكم الأدمن 🛡️

المشروع الآن فيه لوحة تحكم كاملة داخل الموقع نفسه لصاحب المنصة، تسمح بإدارة كل شيء دون الحاجة لفتح Supabase يدوياً:

- **الحيوانات**: تعديل أو حذف أي إعلان حيوان لأي مستخدم.
- **العيادات**: إضافة عيادة جديدة، تعديل بياناتها، حذفها، وحذف أي تعليق/تقييم مخالف عليها.
- **المجتمع**: حذف أي منشور مخالف من ملتقى المجتمع.
- **المستخدمون**: عرض كل المستخدمين وترقية/تنزيل صلاحية الأدمن لأي حساب.

### كيف تُفعّل حسابك كأدمن (خطوة لمرة واحدة)

1. أنشئ حسابك العادي في الموقع أولاً (تسجيل عادي بالبريد وكلمة المرور).
2. من Supabase Dashboard → **SQL Editor** → نفّذ هذا الأمر بعد استبدال البريد ببريدك:
   ```sql
   update public.profiles set role = 'admin'
   where id = (select id from auth.users where email = 'your-email@example.com');
   ```
3. سجّل خروج من الموقع ثم سجّل دخول مرة أخرى.
4. افتح القائمة الجانبية (☰) — ستجد الآن زر أزرق **"لوحة تحكم الأدمن 🛡️"** في الأعلى، وأيضاً أيقونة درع بجانب صورتك الشخصية.

بعدها تقدر ترقّي أي مستخدم آخر إلى أدمن مباشرة من تبويب "المستخدمون" داخل اللوحة نفسها، دون الحاجة للرجوع إلى SQL مرة أخرى.

## بنية المشروع (ما الجديد)

```
supabase/
  schema.sql          ← مخطط قاعدة البيانات الكامل (شغّله مرة واحدة في Supabase)
  seed.sql            ← بيانات ابتدائية اختيارية (عيادات + منشورات)
src/lib/
  supabaseClient.ts   ← إعداد اتصال Supabase
  db.ts               ← كل عمليات القراءة/الكتابة (pets, clinics, posts, favorites, auth, admin)
  storage.ts          ← رفع الصور والفيديوهات إلى Supabase Storage
src/components/
  AdminPanel.tsx      ← لوحة تحكم الأدمن الكاملة
api/gemini/chat.ts    ← دالة Vercel Serverless لمستشار أليف الذكي (بديل خادم Express في الإنتاج)
vercel.json           ← إعدادات النشر على Vercel
```

`server.ts` القديم ما زال يعمل محلياً عبر `npm run dev` (فيه نفس منطق الذكاء الاصطناعي)، بينما في الإنتاج على Vercel تُستخدم `api/gemini/chat.ts` تلقائياً بدلاً منه.

## ملاحظات مهمة

- **الصور والفيديوهات**: تُرفع الآن مباشرة إلى Supabase Storage (bucket `aleef-media`) بدلاً من تخزينها كنص Base64 داخل قاعدة البيانات. يتم حفظ الرابط العام (public URL) فقط في الأعمدة `image_url` / `image_urls` / `video_url`، مما يجعل قاعدة البيانات أخف وأسرع، ويسمح برفع صور وفيديوهات حقيقية دون أي حدود على حجم صف قاعدة البيانات. الحد الأقصى: 5 ميجابايت لكل صورة، و25 ميجابايت لكل فيديو.
- **الأمان**: كل الجداول محمية بـ Row Level Security، بحيث لا يستطيع أي مستخدم تعديل أو حذف حيوان ليس ملكه. الأدمن فقط (بحسب عمود `role` في جدول `profiles`) يقدر يتخطى هذا القيد للإشراف والمراجعة. إضافة صورة لعيادة من زائر عادي تمر عبر دالة آمنة (`add_clinic_image`) تلمس فقط حقل الصور، ولا تسمح له بتعديل اسم أو هاتف أو عنوان العيادة. بيانات البريد الإلكتروني للمستخدمين غير مرئية لأي أحد سوى صاحبها والأدمن.
- **بيانات عامة بحكم طبيعة المنصة**: رقم هاتف واسم صاحب أي إعلان حيوان يظهر للجميع (حتى الزوار غير المسجلين) لأن هذا ضروري لعمل منصة تبني/بيع كهذه — تماماً كموقع "حراج" أو ما شابه. إن أردت إخفاء الهاتف عن غير المسجلين لاحقاً، هذا تعديل بسيط يمكن إضافته.
- **حذف حساب مستخدم بالكامل**: هذا يتطلب صلاحية خاصة (service role) غير متاحة من المتصفح لأسباب أمنية، لذا يبقى من Supabase Dashboard → Authentication → Users → حذف المستخدم مباشرة.
- **التكلفة**: كل من Supabase وVercel لديهما خطة مجانية سخية تكفي هذا النوع من المواقع (قاعدة بيانات حتى 500 ميجابايت، ونشر غير محدود على Vercel).

## تحديثات جديدة (الدفعة الأخيرة)

- **التحكم بحجم الصور عند الرفع**: عند إضافة صورة لأي إعلان حيوان أو عيادة، تظهر تلقائياً أداة اقتصاص (Crop) تفاعلية — المستخدم يسحب ويحجّم إطار الاقتصاص بنفسه، ويشوف الأبعاد الناتجة مباشرة، قبل ما يضغط "قص وإضافة الصورة". هذا يعطيه تحكماً حقيقياً بحجم وإطار الصورة بدل خيارات جاهزة مسبقة.
- **حذف تلقائي للصور من التخزين**: عند حذف أي إعلان حيوان (من صاحبه أو من الأدمن)، تُحذف صوره وفيديوهاته تلقائياً من Supabase Storage. يتم هذا من كود التطبيق مباشرة (`src/lib/db.ts`) عبر Storage API الرسمية، وليس عبر Trigger في قاعدة البيانات، لأن Supabase تمنع صراحةً أي حذف مباشر لملفات Storage عبر SQL.
- **حذف تلقائي للإعلانات بعد 90 يوماً (مع صورها)**: عبر وظيفة مجدولة على Vercel (`api/cron/expire-pets.ts`) تعمل يومياً الساعة 3:00 صباحاً UTC، تحذف أي إعلان حيوان مضى عليه أكثر من 90 يوماً **مع** كل صوره وفيديوهاته من Storage — راجع قسم "الإعداد الإضافي" أدناه، فهذي الميزة تحتاج خطوتين إضافيتين في Vercel لتفعيلها.
- **تعليقات الملتقى**: أصبح بإمكان المستخدمين المسجلين التعليق فعلياً على منشورات ملتقى أليف (جدول `post_comments` جديد في قاعدة البيانات).
- **تاريخ النشر**: يظهر الآن تاريخ نشر كل إعلان حيوان في بطاقته وصفحة تفاصيله.
- رقم التواصل الرسمي للمنصة أصبح `00967781003988` (واتساب فقط).
- عنوان الموقع في المتصفح أصبح "أليف اليمن - منصة الحيوانات الأليفة" بدل الاسم الافتراضي.

## إعداد إضافي مطلوب: الحذف التلقائي الكامل بعد 90 يوماً

هذي الميزة تحتاج مفتاحين إضافيين في Environment Variables على Vercel (بجانب `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` و`GEMINI_API_KEY` الموجودين مسبقاً):

1. **`SUPABASE_SERVICE_ROLE_KEY`**: من Supabase Dashboard → Project Settings → API → **service_role key** (وليس anon key — هذا مفتاح حساس جداً، لا يُستخدم أبداً في كود المتصفح، فقط هنا كمتغير بيئة على الخادم).
2. **`CRON_SECRET`**: أي نص عشوائي طويل تختاره بنفسك (مثال: `aleef-cron-x9K2mP7qL4`)، يُستخدم لمنع أي شخص من استدعاء رابط التنظيف يدوياً من الإنترنت.

⚠️ **مهم**: `SUPABASE_SERVICE_ROLE_KEY` يجب أن يكون بدون بادئة `VITE_` (خلافاً لبقية المفاتيح)، حتى يبقى على الخادم فقط ولا يُضمَّن أبداً في كود الموقع الذي يصل للمتصفح.

بعد إضافة المتغيرين، أعد النشر (Redeploy) من Vercel. Vercel يكتشف تلقائياً إعداد `crons` في `vercel.json` ويجدول الوظيفة بنفسه — لا حاجة لأي إعداد إضافي.
